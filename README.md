# Student Task Manager

## 1. Описание проекта

Student Task Manager - учебный проект на языке Python, предназначенный для разработки приложения по управлению учебными задачами студентов.

## 2. Цель проекта

Изучить основы программирования на Python и научиться создавать и публиковать IT-проекты на GitHub.

## 3. Основные функции

- Вывод названия программы.
- Вывод сообщения о проекте.
- Запуск программы через функцию main().
- Выполнение кода при запуске файла main.py.

## 4. Используемые технологии

- Python
- Visual Studio Code
- Git
- GitHub
- Markdown

## 5. Требования

- Windows
- Python 3
- Visual Studio Code
- Git

## 6. Запуск программы

1. Скачать проект с GitHub.
2. Открыть папку проекта в Visual Studio Code.
3. Открыть терминал.
4. Выполнить команду:

   `py main.py`
